# 林间 Shelter · 雨夜木屋

一个本地运行的 Three.js / WebGL 2 实时交互场景。场景模型、木纹、织物、森林树影、雨滴与环境音均由程序生成；不是静态背景图，也不是离线渲染视频。

## 开始体验

用新版 Chrome、Edge 或 Safari 打开同目录的 `forest-shelter.html`。这是自包含文件，约 900 KB，不需要安装依赖、不需要外部 CDN，也不需要联网。

浏览器需要开启硬件加速并支持 WebGL 2。第一次点击右上角「开启声音」后，环境音才会开始播放；这是浏览器的音频自动播放限制。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标 / 单指拖动 | 轨道视角环顾，带房间边界约束；「躺下听雨」时改为躺着转头 |
| 滚轮 / 双指捏合 | 拉近或拉远；「躺下听雨」时滚轮调节视野 |
| 环顾小屋 | 回到卧室全景 |
| 躺下听雨 | 平躺在枕头上仰望天窗：床头方向在画面上方，拖动可左右转头、抬低下巴 |
| 炉边小憩 | 靠近壁炉、茶杯（清晨为咖啡）和书架 |
| 点击天窗 | 只擦除当前格的内侧雾气，随后在数十秒内缓慢回雾；外侧流水仍然存在 |
| 点击茶杯 / 咖啡 | 加强杯口蒸汽，随后缓慢回落 |
| 点击灯罩 / 炉门 | 切换床头灯 / 壁炉 |
| 右侧设置 | 调雨势、清晨 / 深夜、灯火、环境音量 |
| 沉浸模式 | 隐藏操作界面；按 Esc 或右上角按钮退出 |
| 键盘 1 / 2 / 3 | 在焦点不位于控件时切换三个视角 |

手机默认收起设置，点击右上角调节图标展开；矮屏可在设置面板内部滚动。

## 已实现

- 约 33.4° 的大面积斜面玻璃天窗，木梁结构及封闭卧室。
- 深色木地板、羊毛质感地毯、床品、抱枕、针织毯、书架、书本、拖鞋和置物篮。
- 六格独立的玻璃水系统：小雨水珠停留，中雨水珠合并、沿坡滑落并吞并沿途水珠，暴雨平滑过渡为连续水膜。
- 非周期流动噪声、宽窄流道、下沿积水、贴合玻璃坡面的框边汇流与冲击涟漪；运动距离连续积分，拖动滑块不会使雨丝或水膜跳回原位。
- 室外专用透射画面与室内反射分离；暴雨使用有限幅度折射、沿坡多采样模糊和低能量反射，避免树影熔化和大面积金色镜面。
- 分近远层的 GPU 雨丝、屋顶与树冠飞溅、湿润树影和风偏；可写入的逐格回雾遮罩支持点击擦除。
- 深夜：冷蓝雨夜、暖灯、动态火焰、火星、轻烟和近似体积光。
- 桌面启用 SSAO、柔和 bloom 和阴影；窄屏关闭 SSAO 并降低像素倍率。
- Web Audio 实时合成点状滴答、沙沙雨声、暴雨流水声、风声与炉火；各音层随雨量连续混合，关闭壁炉会同步停止炉火音层。
- 闪电同步提亮天空、环境和水面高光，雷声在 2–4 秒后触发。降低雨量会拉远雷声距离感。
- 页面进入后台时暂停渲染和音频；返回页面后恢复。

## 清晨

「天色」里的「清晨」替换了原来的「黄昏」。天色只改变光线与氛围，雨量仍由「窗外的雨」滑块独立控制；切换天色不会重置雨量。

- 深夜与清晨之间约 4 秒平滑渐变：天空转亮、晨雾显现、台灯和炉火渐暗、阳光从天窗照入、鸟鸣淡入；渐变中途反向切换会从当前值继续过渡。
- 小雨：淡青蓝天空、日轮光晕；阳光穿过天窗，在床和地毯上投下带窗框阴影的光斑。空气里的光束由体积光生成，只出现在真正被太阳照到的区域，会被窗框自然切开，也与床上、地上的光斑对齐；光束里有浮尘，远处有淡彩虹、树枝间起落的小鸟和远处鸟群。
- 中雨（清晨默认氛围）：珍珠灰漫射光，无明显光柱，木墙呈温润浅棕；玻璃水痕在亮背景下逆光透亮。
- 暴雨：青灰「白天的阴沉」，远树隐入雨雾，鸟消失；壁炉余烬自动微亮，室内暖光重新显出来。
- 远处三层山脊在雾中若隐若现；林间晨雾层高度限制在树干下半段，不会进入室内。
- 清晨整体曝光低于深夜，避免晨光发白。
- 室内：主光源改为天窗自然光；台灯和壁炉在清晨默认关闭，壁炉只剩暗红余烬；被子掀开一角；茶杯换成冒热气的咖啡。清晨和深夜分别记住手动开关的灯火设置。
- 界面：时间显示 06:40；左下主文案随雨量切换为「晨光，落在被角。」「一场安静的晨雨。」「今天，不用出门。」，副标题为「世界在窗外醒来。」。
- 声音：鸟鸣密度随雨量递减（暴雨时为零）、树叶滴水、针叶林风声，暴雨增加屋顶低频轰鸣。

## 验证与边界

- 雨系统更新后在本机 Chrome 验证了桌面与 390×844 手机布局；之前版本另测过 320×568。清晨版本另验证了 390×844 手机布局。
- 新雨系统验证了小雨到暴雨切换、暴雨回退、六格隔离、近景仰视、点击擦雾、模拟计数和雷声延迟。木屋其余原有交互保持不变。
- 清晨验证了三档雨量的画面与文案、昼夜往返时雨量保持不变、清晨手动灯火设置在往返切换后保留、暴雨时鸟鸣归零、炉边视角的咖啡点击互动；Node 校验覆盖 4 秒渐变、中途反向、雨量独立和晨间天气连续变化。
- 模拟校验覆盖连续混合、合并体积、分格隔离、坡度速度差、下沿排水和 60 秒暴雨到小雨运行。
- 构建与 JavaScript 语法检查通过；浏览器未报告着色器或运行错误。
- 音频通过浏览器启停与运行状态验证，未进行录音或人工听感评测。
- 视觉定位是可实时运行的暖调 Cozy 风格原型，不是影视级照片写实。水珠采用二维状态模拟，水膜、折射、飞溅和排水采用实时着色近似，不是完整三维流体仿真。
- 框边排水目前表现为贴坡汇流和外侧溢水视觉层，不包含建筑排水管网或完整的离檐水帘流体计算。
- 「躺下听雨」在触屏上支持单指转头，暂不支持双指缩放视野。
- 清晨需求中的可选项（窗台野花、林间松鼠或小鹿、溪流或啄木鸟声）未实现。
- 当前采用轨道相机，不包含 WASD 第一人称走动。房间有边界限制，但不含完整家具碰撞系统。
- 本地交付，未发布到任何云端服务。

## 源码

`forest-shelter-source.zip` 包含场景、音频、界面、构建脚本和依赖锁文件，不包含 `node_modules`。

解压后在 `work` 目录执行：

```sh
npm ci
node build.mjs
```

生成的自包含页面位于相邻的 `outputs` 目录。

## 雨系统诊断

页面地址加 `?rain=100` 可以直接进入暴雨，加 `?rain=18` 可以直接进入小雨；加 `time=morning` 以清晨打开，例如 `?time=morning&rain=18`。

开发检查可使用 `?rain=100&rain-debug`，显示雨量、水膜权重、水珠和合并计数、排水量、模拟时间、闪电及实际雷声延迟。诊断模式提供「测试闪电」按钮，正常页面不显示这些控件。

主要代码文件：

- `work/water-simulation.js`：水珠状态、合并与逐格排水。
- `work/rain-system.js`：图集遮罩、玻璃分格、渲染捕获、落雨粒子与天气时钟。
- `work/rain-shaders.js`：水珠／水膜折射、透射模糊、菲涅尔反射、雨丝及飞溅。
- `work/audio.js`：各雨量对应的声音混合、延迟雷声和清晨鸟鸣。
- `work/daylight.js`：清晨随雨量变化的光照参数与昼夜渐变。
- `work/morning-world.js`：清晨天空、太阳、林间光束、晨雾、山脊、彩虹、鸟和浮尘。
- `work/sunlight-pass.js`：清晨室内体积光，沿视线按太阳阴影贴图采样。
